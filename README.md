# Пластина Хладни

Интерактивная модель фигур Хладни. Песок на звучащей пластине сползает туда, где она не движется, — рисунок создаёт не колебание, а его отсутствие.

**Демо:** https://olegboook-dcat.github.io/Hlandi-Plastin/

![Пластина Хладни](https://img.shields.io/badge/demo-live-6FA88C)

## Что это

Одностраничное приложение на чистом HTML + Canvas + Web Audio, без сборки и зависимостей. Семь тысяч точек хаотично дрожат тем сильнее, чем сильнее в этом месте колебание пластины, и оседают на узловых линиях — там, где движения нет.

- **m** и **n** задают форму колебания.
- Тон берётся прямо из них: две частоты, `55·m` и `55·n` герц, поэтому отношение чисел на экране слышно как музыкальный интервал.
- **Микрофон** отдаёт управление голосу: громкость трясёт пластину, высота голоса выбирает фигуру.

## Запуск локально

Файл статический, но микрофон и Web Audio требуют защищённого контекста, поэтому открывать лучше через локальный сервер, а не как `file://`:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Публикация на GitHub Pages

1. Settings → Pages
2. Source: **Deploy from a branch**
3. Branch: выбранная ветка, папка `/ (root)`

Микрофон работает только по `https` — на `github.io` это выполняется автоматически.
